## 四、发布前的处理建议

1. **逐条核对 A 组上游的 LICENSE**：把核实结果补进本文件第二节的表格。
   明确标注「允许再分发 / 仅限非商业 / 禁止再分发」。
2. **对 C 组补来源**：能说明来源的补进来；确实说不清的，从 `extension/bank/` 中移除该文件，
   或把它移出仓库、改为「用户自备题库地址」加载。移除一个类别只需删掉 `bank/` 下的 JSON
   并同步更新 `bank/index.json`，插件会自动按索引加载。
3. **NC 条款注意**：CMMLU 官方为 **CC BY-NC-SA 4.0**（非商业 + 相同方式共享，已核实其仓库 README「许可证」一节；
   该仓库没有 LICENSE 文件，所以 GitHub API 报 NOASSERTION，不要据此以为它无授权）。
   若未来有商业化打算，`05_cmmlu.json` 必须替换或下架。
4. **保留出处**：在每个题库文件的 `category` 字段旁增加 `source` 字段，便于溯源，
   代价是每个 JSON 增大几 KB（45 个文件合计不到 100 KB，可接受）。

## 六、已移除的类别（别再加回来）

### `40_逻辑推理.json` —— 72,378 题，2026-10-28 移除

**来源**：ModelScope `chenr1209/Logical_reasoning_choice`，数据集卡片标 Apache License 2.0（许可本身干净）。

**移除原因不是许可，是内容不可用**。实测画像：

| 指标 | 实测值 | 说明 |
|---|---|---|
| 题干中位长度 | 27 字 | 只有一句话，没有题面条件 |
| 带「选择题 N：」模板前缀 | 99.0% | 机器生成的合成数据特征 |
| 题干不含任何前提线索 | **60.9%**（44,087 题） | 解题所需的谜题上下文**没有被存进数据集** |
| 同一题干对应多个不同答案 | **1,549 种题干** | 例：「黄色房子的主人喜欢什么饮料？」答案出现过 (0)(1)(2) |

样本：

```
选择题 3： Bob的办公椅是什么颜色？        [红色, 蓝色, 绿色, 不确定] → 3
选择题 1： 哪个城市的总收入最高？          [阿瓦隆, 贝尔加德, 卡米洛特, 德拉科尔] → 2
选择题 4： 玩家完成所有任务后，总共获得的金币数和经验值分别是多少？
```

这是给模型做强化训练用的合成逻辑谜题集（RL-Reasoning / Karel 那一类），**不是考题**。

**为什么"没用"还不够，要说"有害"**：插件是模糊匹配 + 选项校验。学生遇到真逻辑题「谁穿着红色衣服？」，若选项文本恰好能对上，就会命中这 7 万条里的某一条并**自信地填一个来自另一道谜题的随机答案**。它占原库 39%，短题干候选池越大，撞车概率越高。

**移除后**：主包 46 类 / 186,256 题 → **45 类 / 113,878 题**，体积 41 MB → 29 MB，加载 7.3 s → 约 4.5 s，内存 245 MB → 约 150 MB。**有效题量几乎未降**，因为被删的这批本来就答不对。

备份：`_removed-逻辑推理-源.json.bak`、`_removed-逻辑推理-库.json.bak`（确认无误后可删）。
