# 安装教程（从零开始）

这份文档假设你**没装过任何浏览器扩展**，跟着做完即可。
全程约 5 分钟，不需要会写代码，不需要装 Node.js、Python 或任何开发工具。

> 只想先看看效果？可以不装题库，直接跳到第 5 步，用「仅 AI」模式。

---

## 一、先确认你的浏览器

| 浏览器 | 是否支持 | 打开扩展管理页的地址 |
|---|---|---|
| Microsoft Edge | ✅ | `edge://extensions` |
| Google Chrome | ✅ | `chrome://extensions` |
| 其他 Chromium 内核（Brave、Vivaldi、360 极速等） | 一般可以 | 各自有类似页面 |
| Firefox / Safari | ❌ 不支持 | — |

浏览器版本没有严格限制，**近两年内更新过的 Edge 或 Chrome 都可以**。

---

## 二、下载两个文件

### ① 插件本体（必需）

打开 <https://github.com/cspyz/quizlens>

在页面右上角找到绿色的 **`Code`** 按钮，点开，选最下面的 **`Download ZIP`**。

> 找不到 `Code` 按钮？直接点这个链接也会开始下载：
> <https://github.com/cspyz/quizlens/archive/refs/heads/main.zip>

下载得到一个 `quizlens-main.zip`，约 4 MB。

### ② 题库包（可选）

打开 <https://github.com/cspyz/quizlens/releases/tag/bank-v1>

在页面下方 **Assets** 区域，点 **`quizlens-bank-v1.zip`**，约 8.2 MB。

- 想要大学、高中课程那部分，再下 `quizlens-bank-ceval-v1.zip`（0.76 MB），两个可以同时装。
- **不想装题库也能用**：插件有「仅 AI」模式，只是每题都要调一次模型，慢一些、花钱。

---

## 三、解压并摆放文件

### 1. 解压插件本体

右键 `quizlens-main.zip` → 解压到当前文件夹，得到一个 `quizlens-main` 文件夹。

打开它，里面应该长这样：

```
quizlens-main\
├── extension\        ← 注意这个
├── tools\
├── docs\
├── README.md
└── ...
```

### 2. 把题库放进去（不装题库可跳过）

右键 `quizlens-bank-v1.zip` → 解压，得到一个 `bank` 文件夹。

**把整个 `bank` 文件夹剪切，粘贴到 `quizlens-main\extension\` 里面。**

放好之后应该是这样：

```
quizlens-main\
└── extension\
    ├── manifest.json      ← 关键文件，必须在这一层
    ├── content.js
    ├── popup.html
    ├── icons\
    └── bank\              ← 你刚粘进来的
        ├── index.json
        ├── 01_jiakao_car.json
        └── ...（共 45 个 json）
```

> **这一步最容易错。** `bank` 必须和 `manifest.json` 在**同一层**。
> 如果放成了 `extension\bank\bank\...`，插件会读不到题库。

---

## 四、加载扩展

### Edge

1. 地址栏输入 `edge://extensions` 回车
2. 看**左下角**（部分版本在右侧），打开 **「开发人员模式」** 开关
3. 页面顶部出现三个按钮，点 **「加载解压缩的扩展」**
4. 在弹出的选择框里，**进入 `quizlens-main`，选中里面的 `extension` 文件夹**，点「选择文件夹」

### Chrome

1. 地址栏输入 `chrome://extensions` 回车
2. 看**右上角**，打开 **「开发者模式」** 开关
3. 左上角出现三个按钮，点 **「加载已解压的扩展程序」**
4. 同样，选中 `quizlens-main\extension` 文件夹，确定

> **选哪个文件夹是本教程最大的坑。** 要选 `extension`，不是外面的 `quizlens-main`。
> 选错了会提示「清单文件缺失」或「Manifest file is missing」。

---

## 五、确认装好了

加载成功后，扩展列表里会出现一张卡片：**QuizLens 练习助手**，图标是蓝色的。

工具栏上如果没看到图标，点地址栏右边的 **拼图图标** 🧩，找到 QuizLens，点旁边的图钉固定出来。

点一下图标，应该弹出设置面板。看到面板就说明装好了。

**如果装了题库**，把弹窗里的「**答题模式**」选成 **题库匹配**，然后随便打开一个答题页面，右上角会出现悬浮面板。

---

## 六、配置（只有用 AI 才需要）

弹窗里有两处「模式」，别搞混：**输出模式**（AI 回答给多少）和**答题模式**（下面这个）。

「答题模式」有三档：

| 模式 | 要不要配 API | 适合 |
|---|---|---|
| **题库匹配** | ❌ 不需要 | 只查本地题库，命中才填。装完就能用 |
| 题库 + AI 兜底 | ✅ 需要 | 题库没命中时调模型补，命中率最高 |
| 仅 AI | ✅ 需要 | 不装题库，全部靠模型 |

要用 AI，在面板的「AI 接口」填三栏：

| 字段 | 填什么 | 例子 |
|---|---|---|
| **AI Base URL**（OpenAI 兼容） | 服务商给的接口地址，填到 `/v1` 或根路径为止，**不要带 `/chat/completions`**（插件会自动拼） | DeepSeek 填 `https://api.deepseek.com`；OpenAI 填 `https://api.openai.com/v1` |
| **API Key** | 你的 Key，只存在本机 | `sk-...` |
| **模型** | 模型名，可直接下拉选 | `deepseek-chat` |

填完点旁边的「获取模型」可以从下拉里直接挑，再点「测试连接」确认通不通。

截图解题（面板右上角 📷）用另一组配置，在弹窗的「模型」页最下面：

| 界面上的名字 | 怎么填 |
|---|---|
| **视觉模型**（需支持看图） | 填一个支持图片输入的模型名，例如 `glm-4v-flash`（官方标注免费） |
| **视觉 Base URL** | 和上面的 AI 接口是同一家就**留空**，不同家才填它自己的地址 |
| **视觉 Key** | 留空 = 复用上面的 API Key |

## 七、常见问题

| 你看到的 | 原因 | 怎么办 |
|---|---|---|
| 「清单文件缺失」/ `Manifest file is missing` | 加载时选到了外层 `quizlens-main` | 重新点加载，这次选里面的 `extension` |
| 装了题库，但一题都命不中 | 没重新加载扩展 | 回扩展管理页，点卡片上的「重新加载」↻ |
| 扩展页有黄色警告条 | 未上架商店的扩展都会提示 | 正常现象，不影响使用 |
| 提示要「读取和更改所有网站上的数据」 | 插件要适配各种答题站点 | 正常。逻辑全部在本地，不会上传题目 |
| 打开答题页没反应 | 插件只在页面加载时注入 | 按 F5 刷新一次页面 |
| 面板挡住题目了 | — | 面板可以拖动，也能收起 |
| 换电脑后要重装 | 开发者模式加载的扩展不跟账号同步 | 把 `extension` 文件夹拷过去重装一次 |

---

## 八、卸载

1. 扩展管理页找到 **QuizLens 练习助手**
2. 点「移除」
3. 删掉 `quizlens-main` 文件夹

题库数据就在 `extension\bank\` 里，随文件夹一起删掉，系统其他位置不留文件。

---

## 九、更新到新版本

开发者模式加载的扩展**不会自动更新**，需要手动：

1. 重新下载一次 ① 的 ZIP
2. 解压后，用新的 `extension` 文件夹**替换旧的**（先把 `bank` 文件夹拷出来，替换完再放回去，不然题库会被一起删掉）
3. 回扩展管理页点「重新加载」

---

## 十、这个插件要联网吗

| 场景 | 是否联网 | 数据去哪 |
|---|---|---|
| 题库匹配 | ❌ 完全离线 | 不出本机 |
| AI 模式 | ✅ 只连你自己填的接口地址 | 题目发给你配置的那个 API |
| 截图解题 | ✅ 同上 | 截图发给你配置的那个模型 |

插件本身**没有**任何服务器，作者收不到你的任何数据。详见 [PRIVACY.md](../PRIVACY.md)。
