# 题库安装教程

插件本身不含题库（11.4 万题 / 45 类 / 约 29MB，因各来源授权条款不同，单独分发）。
想用**题库匹配**或**题库 + AI 兜底**，需要自己装一次题库。只用 AI 的话可以跳过本文件。

> **题库包已发布**，在仓库的 **Releases** 页：
> 主包 `quizlens-bank-v1.zip`（45 类 / 113,878 题 / 8.2 MB）、补充包 `quizlens-bank-ceval-v1.zip`（25 学科 / 6,856 题 / 0.76 MB）。
>
> ⚠️ **题库数据不适用本项目的 MIT 许可**，各类别上游授权状态不同，约六成题目没有明确的可再分发授权。
> 包内 `LICENSE-DATA.md` 有逐类清单（来源 / 许可 / 能否再分发）。**二次分发或商用前请先读它**，否则只用来自行答题即可。

## 方法一：解压回插件目录（推荐，零配置）

**第 1 步** 下载题库包 `quizlens-bank-v1.zip`。

**第 2 步** 解压，得到一个 `bank` 文件夹，里面有 `index.json` 和 45 个 `.json`。

**第 3 步** 把这个 `bank` 文件夹整个放进插件目录，最终长这样：

```
extension/
├── manifest.json
├── content.js
└── bank/              ← 你放进来的
    ├── index.json
    ├── 01_jiakao_car.json
    └── ...（共 45 个类别文件）
```

**第 4 步** 打开 `chrome://extensions`（Edge 为 `edge://extensions`），在插件卡片上点「重新加载」↻。

**第 5 步** 刷新答题页面，弹窗里选「题库匹配」或「题库 + AI 兜底」，点「开始答题」。

看到日志 **`大题库：45/45 个类别加载成功（来源：扩展内置题库）`** 就成功了。

> 实测：加载 + 建索引约 4.5 秒，之后同一页面内再答题会复用索引，不重复等待。
> 若你解压后看到的是 `bank/bank/` 两层嵌套，说明放错了一层，把里层那个 `bank` 移出来即可。

---

## 方法二：填「题库地址」（想放在别处 / 多人共用时）

不想把 29MB 塞进插件目录，或宿舍几台电脑共用一份时，可以把题库放在任意位置，再告诉插件去哪儿取。

**第 1 步** 把解压出来的 `bank` 文件夹放到任意位置，例如 `D:\bank`。

**第 2 步** 用任意静态服务器托管它。三选一：

| 你装了 | 命令（在 `bank` 的**上一级**目录执行） |
|---|---|
| Python | `python -m http.server 8000` |
| Node.js | `npx http-server -p 8000` |
| 都没有 | 用方法一，不需要服务器 |

**第 3 步** 浏览器地址栏访问 `http://localhost:8000/bank/index.json`，能看到一串 JSON 才算通。

**第 4 步** 插件弹窗 →「高级 · 题库地址」→ 填 `http://localhost:8000/bank/`（**结尾的 `/` 要留着**）→ 开始答题。

日志会显示 `来源：自定义题库地址`。

> 填了「题库地址」后，它优先于插件目录里的 `bank/`。
> 放在局域网服务器上给多台机器用同理，填 `http://192.168.x.x:8000/bank/` 即可。

## 怎么确认装好了

开启「答题时显示面板」，日志开头几行应该出现：

```
正在加载题库并建索引（45 个类别，首次约 2~5 秒）…
  题库加载 45/45：46_fill_blank_stem.json
大题库：45/45 个类别加载成功（来源：扩展内置题库）
题库索引构建完成：共 113805 题（来源：扩展内置题库，4xxxms），模糊阈值 75%
```

`共 113,805 题` 左右是正常值（113,878 题里有约 73 条题干归一化后为空，被索引跳过）。

## 常见问题

**日志说「大题库没加载到」？**
按提示的已尝试列表对号入座：

| 提示 | 原因 | 怎么办 |
|---|---|---|
| `扩展内置题库(Failed to fetch)` | 方法一的 `bank/` 没放对位置，或放好后没点「重新加载」 | 检查目录层级，然后到扩展管理页点 ↻ |
| `当前页面(HTTP 404)` | 这条是正常回退提示，不是你出错 | 忽略，看上一条 |
| `自定义题库地址(HTTP 404)` | 地址末尾少 `/`，或 `bank` 少一层 | 用第 3 步的 URL 先手动验证 |
| `返回的不是合法 JSON` | 那个地址返回的是 404 页面或目录列表 | 同上，先手动访问确认 |

**装好了但很多题「未匹配」？**
内置题库覆盖驾考、医学、计算机、考研政治、公务员等 45 类，不是所有卷子都在里面。改用「题库 + AI 兜底」，未命中的题会自动交给 AI。

**只想用 AI，不想装题库？**
可以。弹窗「答题模式」选「仅 AI」，完全不碰题库，也不需要本文件任何步骤。

**能不能把题库地址填成本地文件夹路径（`file:///D:/bank/`）？**
目前不行——后台只放行 `http(s)` 与 `chrome-extension` 协议。技术上已验证扩展的后台能读取本地文件，只是这道白名单挡着；放开后这一步可以省掉服务器，但尚未实现。在那之前，本地文件夹请用方法一。

## 可选包：C-Eval 大学与高中课程

`bank-ceval` 是独立题库包，**25 学科 / 6,856 题**，补大学（经济学、工商管理、艺术学、教育学、法学、大学编程、大学物理 / 化学等）与高中（语文、数学以外各科）课程。

下载 `quizlens-bank-ceval-v1.zip`（0.76 MB），SHA-256：
`9504d8e054517883c889318ecab5bd7d0c8a9b82e1aea8e700aa52024de96cce`

安装方式与主包完全相同：把它的 `*.json` 和 `index.json` 一起放进 `extension/bank/`。两个包的编号已错开（主包 `01`~`46`，本包 `501`~`525`），合并后是 **70 类 / 120,734 题**，实测可在真浏览器中一次性加载并正确命中。

⚠️ **本包许可与主程序不同**：C-Eval 数据集为 **CC BY-NC-SA 4.0（非商业、署名、相同方式共享）**，不得用于商业用途。详见包内 `LICENSE-DATA.md`。

本包已剔除两类学科：

- **与主包重复的**——操作系统、计算机网络、计算机组成、医学、考研政治各科等，主包题量不低于它，重复导入只会制造跨库重题；
- **选项含 LaTeX 公式的**——高等数学、概率论与数理统计、离散数学、高中数学。这类题在网页上是渲染后的式子，而题库匹配会把 `$\frac{A+1}{A-1}$` 归一化成 `fracA1A1`，与页面的 `A1A1` 对不上，必然判未命中。**数学类题目请走 AI 模式**，比题库可靠。
